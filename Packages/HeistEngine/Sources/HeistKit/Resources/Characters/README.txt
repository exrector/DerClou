Runtime character assets live here. The main `<character>.usdz` contains the
visible rig and canonical Walk binding. Files named
`<character>_<Semantic>.usdz` are non-displayed single-action carriers loaded
by `LevelSceneBuilder` into `CharacterAnimationLibrary`.

All of these files are generated by `ArtSource/Tools/apply_animation.py` from
the character's own `.blend`; downloaded action FBX meshes must never be copied
here directly.
