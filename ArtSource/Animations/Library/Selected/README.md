# Curated runtime selections

Only reviewed clips belong here. One semantic can point to one source plus a
small number of intentional style/role variants.

Required initial vocabulary:

- Idle
- StartWalking
- Walk
- StopWalking
- ShortStep
- TurnLeft
- TurnRight
- TurnAround
- OpenDoor
- CloseDoor
- UnlockDoor
- Lockpick
- PressButton
- PullLever
- Look

Every accepted selection records source ID, intended actor/style, loop policy,
measured native pace, root-motion treatment, and visual-review status.
