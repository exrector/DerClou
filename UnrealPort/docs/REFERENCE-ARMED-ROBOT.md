## 2. Главное правило

**Поправку хранит скелет, а не компонент.**

Сокеты на меше `SK_Robot_scout_R21` уже несут всю выверенную геометрию хвата.
Поэтому оружие вешается в сокет с **нулевым смещением и нулевым поворотом**.
Никакой подгонки на компоненте больше не требуется — и не должно
появляться.

| Сокет | Кость | Смещение | Поворот (pitch, yaw, roll) |
|---|---|---|---|
| `Socket_Weapon` | `hand_r` | `(-10.574, 4.335, 0.836)` | `(5.829, -14.136, -12.111)` |
| `Socket_Weapon_L` | `hand_l` | `(10.566, -4.100, -0.488)` | `(-7.069, 156.597, -162.456)` |

Значения получены не подбором: пользователь выставил посадку руками на
компонентах, после чего поправка была математически свёрнута в сокеты
(`compose_transforms`). Проверка: после переноса пистолеты сместились на
**0.001 см**, то есть остались на месте.

У меша есть ещё два сокета от прошлых работ — `WeaponSocket` и
`FlashlightSocket`. Они к эталону отношения не имеют.

## 3. Как воспользоваться

В уровне `Lvl_GrantDemo` есть папка **`ЭТАЛОН`** с шестью готовыми актёрами
(`y = -800`, подписаны жёлтым):

| Актёр | Анимация |
|---|---|
| `REF_1_Idle` | `Idle` |
| `REF_2_FireRight` | `Primary_Fire_Med_A` |
| `REF_3_DoubleShot` | `DoubleShot_Fire_Rt` |
| `REF_4_Walk` | `Walk_Fwd` |
| `REF_5_JogStart` | `Jog_Fwd_Start` |
| `REF_6_JogStop` | `Jog_Fwd_Stop` |

У каждого два пистолета в сокетах. **Копировать через Ctrl+C / Ctrl+V** —
привязка к сокетам переносится вместе с актёром.

Собрать с нуля тоже просто:

1. `SkeletalMeshActor`, меш `SK_Robot_scout_R21`
2. Компонент `SkeletalMeshComponent` с мешем `Rigged_M1911`
3. Привязать в `Socket_Weapon` (и `Socket_Weapon_L` для второго)
4. Смещение и поворот компонента — **нули**

## 4. Совместимость скелетов

У скелета `/Game/Robot_scout_R_21/Mesh/UE4_Mannequin_Skeleton` — **26**
совместимых записей. Из них две добавлены вручную:

- `AnimStarterPack/.../UE4_Mannequin_Skeleton`
- `ParagonTwinblast/.../TwinBlast_Skeleton`

**Без этих записей анимации соответствующих паков не заиграют.** Не чистить.

Направление важно: список должен быть **у скелета робота**, потому что
именно на нём проигрываются чужие анимации.

## 5. Что не получилось и почему

Была попытка собрать эталон как Blueprint (`BP_Ref_ArmedRobot`), чтобы
таскать его как ассет. **Не сработало:** после компиляции привязка
компонентов к сокетам слетает — сокет становится `None`, компоненты
падают в начало координат. Через доступный Python API шаблон Blueprint
привязку к сокету не удерживает. Blueprint удалён, эталон живёт актёрами
в уровне.

Если понадобится именно ассет, а не актёры — делать Blueprint руками в
редакторе (Create Blueprint From Selection), не скриптом.
